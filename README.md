# carrey-profolio

這個程式碼庫目前是**初始化狀態**：
- 只有 `.git/`（版本控制資料）
- 以及 `.gitkeep`（保留空目錄／占位用途）

## 給新手的導覽

### 1) 目前整體結構

```text
carrey-profolio/
├── .git/        # Git 版本控制內部資料
└── .gitkeep     # 佔位檔，代表專案尚未放入實際程式碼
```

目前還沒有前端、後端、設定檔、測試、或 CI/CD 檔案。

### 2) 你現在需要先理解的重點

1. **這是一個空白專案骨架**
   - 代表你可以自由決定技術棧（例如 React / Next.js / Vue / Node.js / Python 等）。

2. **先定義目標，再建立結構**
   - 「profolio（portfolio）」通常是作品集網站。
   - 建議先確認：
     - 目標使用者是誰？
     - 需要哪些頁面（首頁、關於我、作品、聯絡）？
     - 是否需要後台或 CMS？

3. **先建立最小可運作版本（MVP）**
   - 先做出一個可部署、可瀏覽、可更新內容的版本，再逐步美化。

### 3) 下一步學習與實作路線（建議）

1. **Git 基礎**
   - 學會 `git status`、`git add`、`git commit`、`git log`。

2. **選擇一個框架並初始化**
   - 前端新手可從 `Next.js` 或 `Vite + React` 開始。

3. **建立標準目錄**
   - 例如：
     - `src/`：程式碼
     - `public/`：靜態資源
     - `tests/`：測試
     - `docs/`：文件

4. **加入基礎工程化**
   - Lint（ESLint）
   - Formatter（Prettier）
   - 測試（Vitest/Jest）
   - CI（GitHub Actions）

5. **部署第一版**
   - 可先部署到 Vercel / Netlify，建立可公開連結。

## 推薦的第一個里程碑

- 第 1 天：初始化框架並跑起首頁
- 第 2 天：完成「關於我」與「作品列表」頁面
- 第 3 天：加入 RWD、SEO 基本設定、並部署
